# Visualize LC
Interactive visualizations for LeetCode problems to help understand algorithms step-by-step.
## Features
- **Step-by-step execution**: Watch algorithms run in real-time with visual feedback
- **Interactive controls**: Next step, auto-play, and pause functionality
- **Educational**: Perfect for learning and teaching data structure problems
## Problems
Currently includes visualization for [LeetCode 2352 - Equal Row and Column Pairs](2352%20Leetcode%20-%20Equal%20Row%20and%20Coulumn%20Pairs)
## Usage
Open the HTML file in your browser to start visualizing the algorithm execution.
